## 📌 이력 기록 원칙 (Logging Standard)
다음과 같은 순간에 신규 로그(`LOG_XXX_...md`)가 생성되고 본 인덱스에 업데이트됩니다:
1. **패러다임의 전환**: 투자/사업/인생 전략에서 새로운 핵심 인사이트를 발견했을 때
2. **주요 기술/도구의 획득**: 새로운 자동화 기법, AI 도구 활용법, 재정 시뮬레이션 모델 개발 시
3. **사용자 마일스톤 달성**: 시드머니 1단계 달성, 파이프라인 첫 수익 발생 등 실전 성과 달성 시
4. **대규모 지식 흡수**: 임팩트 있는 유튜브/도서/칼럼을 심층 분석하여 시스템에 내재화했을 때
