# [이력 #010] 올인원 부자 전략 포털 & 인터랙티브 웹 대시보드 구축

- **기록일자**: 2026-09-01
- **마일스톤 분류**: 자율형 부자 웹 포털 런칭 (All-in-One Wealth Portal Launch)
- **핵심 목표**: 제안 1~4와 실시간 지표, 계산기, 마크다운 뷰어를 통합하여 사용자가 언제든 한눈에 보고 실행할 수 있는 웹사이트 완성

## 💡 주요 전환점 및 배경 (Turning Point)
- 매번 AI에게 질문하지 않고도, **사용자가 브라우저에서 직접 [제안1~4], [실시간 공포지수/시세], [세액공제/무한매수/건물 수지 계산기], [13개 핵심 MD 지식 뷰어]를 원스톱으로 확인하고 조작할 수 있는 전용 웹 포털**을 구축함.

## 🛠 획득된 웹 포털 핵심 기능 (Portal Features)

1. **통합 홈 & 실시간 대시보드**: CNN Fear & Greed 지수 게이지, 실시간 RWA/NFT 코인 시세, 일일 부자 습관 체크
2. **[제안 1] 절세계좌 & 월배당**: 3대 세대별 포트폴리오 비중 및 연말정산 환급액 계산기
3. **[제안 2] 5분 무한매수 & 공포**: TQQQ 40분할 LOC 1회차 주문 자동 계산기 & 월가 5대 지표 링크
4. **[제안 3] RWA & NFT 인프라**: 블랙록/SWIFT/애플 연동 톱 5 프로젝트 상세 스펙
5. **[제안 4] 꼬마빌딩 밸류애드**: 매매가/대출금리/보증금 입력 시 실투자금, 월이자, 순수익 스트레스 테스트 시뮬레이터
6. **지식 베이스 내장 뷰어**: `docs/` 폴더 내 모든 마크다운 문서를 브라우저에서 즉시 열람
7. **원클릭 실행기**: `실행_부의나침반.bat` 더블클릭으로 즉시 실행
