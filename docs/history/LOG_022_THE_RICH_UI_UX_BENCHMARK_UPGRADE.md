## 2. 신규 탑재된 더리치형 핵심 UI/UX 기능

### 2.1 더리치 4대 핵심 배당 지표 요약 카드 (`view-plan1`)
1. **연간 총 배당금 (`#therich-annual-total`)**: 세전 연간 총 배당 수령액 실시간 집계.
2. **월평균 실수령액 (`#therich-monthly-avg`)**: 매월 자동 입금되는 월평균 현금흐름.
3. **포트폴리오 배당률 (`#therich-yield-rate`)**: 투자원금 대비 현재 시점 배당수익률.
4. **10년 복리 월배당 (`#therich-10y-monthly`)**: 배당 재투자 시 10년 후 눈덩이 복리 월배당금.

### 2.2 더리치 시그니처 12개월 배당 캘린더 막대 차트 (`#monthlyDividendCalendarChart`)
- **1월 ~ 12월 12개 월별 배당금 지급 현황을 감성적인 바 차트로 시각화**.
- **이번 달(Current Month) 강조 모드**: 당월 배당금은 **골드(황금색)** 막대로 자동 하이라이트.
- 분기 배당 집중월(3, 6, 9, 12월)과 월배당 ETF(SOL, TIGER)의 실제 분배 주기를 반영한 정밀 시뮬레이션.
