# 🚀 02. 현금흐름 파이프라인 & 소득 다각화 (Cashflow Pipelines)

> **"잠자는 동안에도 돈이 들어오는 방법을 찾아내지 못한다면, 당신은 죽을 때까지 일해야만 할 것이다."** - 워런 버핏

---

## 1. 5대 파이프라인 분류 (The 5 Pipeline Streams)

```
[소득 다각화 모델]
├── 1. 근로 소득 (Base Cashflow): 시드머니 확보를 위한 든든한 기반
├── 2. 지식/콘텐츠 소득 (Digital Assets): 전자책, 유튜브, 블로그, 뉴스레터
├── 3. 비즈니스/커머스 소득 (Commerce & SaaS): 스마트스토어, 노코드 툴, 자동화 서비스
├── 4. 자본 배당 소득 (Dividend & Yield): 고배당주, 리츠(REITs), 채권 이자
└── 5. 부동산/임대 소득 (Rental Cashflow): 월세, 공간 대여, 무인 매장
```

---

## 2. 무자본/소자본 디지털 파이프라인 구축 전략
1. **AI 기반 콘텐츠 자동화 파이프라인**:
   - 정보성 숏폼/롱폼 비디오 제작
   - SEO 최적화 전문 블로그 (애드센스 + 제휴마케팅)
2. **지식 상품화 (Productize Yourself)**:
   - 본인이 겪은 문제 해결 과정 -> PDF 전자책 / 노션 템플릿 / 템플릿 마켓 판매
3. **제휴 마케팅 (Affiliate Engine)**:
   - 쿠팡 파트너스, 아마존 어필리에이트, SaaS 추천 프로그램

---

## 3. 파이프라인 진척도 관리 규칙
- 각 파이프라인마다 **[월 10만원] -> [월 50만원] -> [월 100만원] -> [월 300만원+]** 단계별 목표 설정
- 발생한 모든 부수입은 100% 자산 매수(3단계 복리 엔진)로 재투자
