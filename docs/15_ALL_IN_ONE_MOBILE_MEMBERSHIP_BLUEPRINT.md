## 🤖 3. AI 자율 투자 제안 엔진 (Autonomous Investment Order Engine)

단순한 데이터 조회가 아니라, **"그래서 오늘 밤 나는 무엇을 얼마에 주문해야 하는가?"**를 1초 만에 산출하여 화면 최상단에 브리핑합니다:

1. **[오늘의 TQQQ 무한매수 오더]**:
   - 사용자의 시드머니 기준 1회분(1/40) 자동 계산
   - `평단가 LOC 주문 0.5회분` + `현재가+5% LOC 주문 0.5회분` + `+10% 자동 익절 지정가`
2. **[이달의 월배당 복리 적립 오더]**:
   - `SOL 미국배당다우존스` 매수 추천 수량 및 이번 달 예상 배당금 자동 계산
3. **[공포지수 역발상 바겐세일 신호]**:
   - 주식 공포지수 25 이하 진입 시 **[🚨 버핏 바겐세일 매수 발동]** 알림 표시

## 📲 4. 모바일 퍼스트(Mobile-First) UI/UX 아키텍처

- **하단 고정 플로팅 도크 (Mobile Bottom Floating Navigation)**:
  - 스마트폰 엄지손가락 영역에 항상 고정되는 5대 핵심 탭바: `[홈]`, `[절세배당]`, `[무한매수]`, `[웹3]`, `[경제뉴스]`
- **PWA (Progressive Web App) 규격 지원**:
  - 홈 화면에 앱 아이콘 추가 시 주소창 없는 100% 풀스크린 네이티브 앱으로 구동.
- **가로 스크롤 없는 스마트 카드 레이아웃**:
  - 360px 모바일 화면에서도 깨짐 없는 완벽한 반응형 픽셀 고정.
